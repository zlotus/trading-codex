# Project Documentation

This directory preserves the context needed to continue development across
devices and sessions.

- [`context.md`](context.md): stable purpose, workflows, architecture, and
  long-term constraints.
- [`implementation-plan.md`](implementation-plan.md): ordered delivery plan and
  acceptance gates.
- [`progress.md`](progress.md): concise current-state and handoff snapshot.
- [`decisions/`](decisions/README.md): durable technical and product decisions
  with their rationale.

Repository instructions and external specifications are normative. Code,
tests, and configuration describe implemented behavior. These documents explain
the enduring context and current direction without replacing those sources.
